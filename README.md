# 仓颉仓库大冒险

一个面向小学 1—6 年级的纯前端互动课件。孩子先选择低年级或高年级路线，再自主选择仓颉遇到的难题，通过任务解决“记录、分类、盘点”中的 1—2 个问题，自动生成个人“办法图”，最后依据办法图完成上台汇报。

## 学习路径

1. **建立身份**：虚拟键盘输入名字，选择初级或高级路线。
2. **自主选择**：不按固定顺序闯关，孩子决定先解决哪个真实问题。
3. **操作验证**：任务中通过判断、分类、核对得到即时反馈。
4. **可视化反思**：系统把孩子的实际操作转成个人“办法图”。
5. **表达迁移**：孩子指着办法图，按“我是谁—解决了什么—怎么做的—发现了什么”完成汇报。
6. **正向收束**：勋章、总分与已解决问题形成完整成就闭环。

## 使用

直接双击 `index.html`，无需安装、账号或服务器。学习进度保存在浏览器 `localStorage` 中。

## AI 预留

代码中以 `AI 接入点` 注释标出了仓颉个性化评价、办法图润色和汇报小助手三个位置。默认使用离线规则，完整流程不依赖联网。
