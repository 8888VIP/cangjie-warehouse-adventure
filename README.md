# 仓颉仓库大冒险

一个面向小学 1—6 年级的纯前端互动课件。孩子先选择低年级或高年级路线，再自主选择仓颉遇到的难题。每个问题都要经历完整六阶段，完成后生成个人“办法图”，最后依据办法图上台汇报。

当前版本为 **神话六关版 V2**：加入云海神仓视觉、三段神话序章、仓颉跳入式陪伴、中文语音、按钮打击音效、自由姓名输入和触控手写名字牌。

## 学习路径

1. **建立身份**：自由输入任意姓名，或使用平板手写键盘/网页触控手写板留下名字印记。
2. **自主选择**：不按固定顺序闯关，孩子决定先解决哪个真实问题。
3. **六阶段操作验证**：每个任务都经过听任务、找线索、动手操作、计算或编码、复查、解释原因六个阶段。
4. **可视化反思**：系统把孩子的实际操作转成个人“办法图”。
5. **表达迁移**：孩子指着办法图，按“我是谁—解决了什么—怎么做的—发现了什么”完成汇报。
6. **正向收束**：仓颉会跳入画面，用本地中文语音表扬、提示和示范汇报，最后通过勋章收束。

## 三个六阶段任务

- **记录任务**：听清任务 → 识别货印 → 逐件验货 → 清点总数 → 编制绳结 → 复查封仓。
- **分类任务**：听清任务 → 确定标准 → 观察属性 → 整理前区 → 整理后区 → 限时找物。
- **盘点任务**：听清任务 → 逐架实数 → 对照记录 → 算出相差 → 判断多寡 → 查因修册。

## 使用

直接双击 `index.html`，无需安装、账号或服务器。学习进度保存在浏览器 `localStorage` 中。

## AI 预留

代码中以 `AI 接入点` 注释标出了仓颉个性化评价、办法图润色和汇报小助手三个位置。默认使用本地评价库、规则和浏览器中文语音，完整流程不依赖联网。
